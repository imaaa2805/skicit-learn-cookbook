
# 📚 Scikit-Learn Cookbook

> Over 80 recipes for machine learning in Python with scikit-learn[cite: 5]

A comprehensive, hands-on collection of Jupyter Notebooks covering the machine learning pipeline — from basic API conventions to linear models and regularization — using [scikit-learn](https://scikit-learn.org/)[cite: 20, 205].

## 📖 Table of Contents

| # | Chapter | Notebook File | Topics Covered |
|---|---|---|---|
| 01 | **API Elements of scikit-learn** | `Chapter_01_API_Elements_of_scikit_learn.ipynb` | Estimators, transformers, pipelines, fit/predict paradigm, get_params/set_params[cite: 20, 205] |
| 02 | **Data Preprocessing** | `Chapter_02_Data_Preprocessing.ipynb` | Scaling, normalization, encoding, imputation, feature engineering, feature selection[cite: 40, 205] |
| 03 | **Dimensionality Reduction** | `Chapter_03_Dimensionality_Reduction.ipynb` | PCA, LDA, t-SNE, variance thresholding, high-dimensional visualization[cite: 72, 205] |
| 04 | **Models with Distance Metrics and Nearest Neighbors** | `Chapter_04_Distance_Metrics_and_KNN.ipynb` | KNN classification, Euclidean/Manhattan metrics, decision boundaries, GridSearchCV, evaluation metrics[cite: 70, 205] |
| 05 | **Linear Models and Regularization** | `Chapter_05_Linear_Models_and_Regularization.ipynb` | Ordinary Least Squares, Ridge (L2), Lasso (L1), ElasticNet, polynomial features, spline interpolation[cite: 94, 205] |

## 🚀 Getting Started

### Prerequisites

- Python 3.9+[cite: 21, 205]
- Jupyter Notebook / Google Colab[cite: 205]

### Installation

```bash
# Clone the repository
git clone [https://github.com/](https://github.com/)<your-username>/scikit-learn-cookbook.git
cd scikit-learn-cookbook

# Install dependencies
pip install scikit-learn numpy pandas matplotlib seaborn jupyter

# Launch Jupyter
jupyter notebook

```

## 💡 How to Use This Cookbook

1. **Sequential learning** — Work through chapters 01–05 in order for a structured machine learning workflow.


2. **Interactive exploration** — Open any `.ipynb` file in Google Colab or your local Jupyter environment to run and modify code recipes.


3. **Reference** — Use individual notebooks as quick references for specific scikit-learn techniques and APIs.



Each notebook is designed with:

* Theoretical overview and mathematical formulations


* Code reproduction from the cookbook recipes


* Visualizations of model results and decision boundaries


* Practical tips and performance analyses
